📖 Teacher Guide — Gesture Molecule Lab
1. Enable Camera
Click Enable Camera & Begin. Allow permission. Hand 40-70cm, good light, plain background. If fails, use mouse.
2. Move & Pinch
Open hand move → rotate. Thumb+index pinch → zoom (inverted). Double pinch → next molecule.
3. Builder (Class 10)
Click 🔧 Builder → choose Carbon count, Bond position, Functional group. Click a C to select (black dot), single pinch = +1 C / add group, double pinch = −1 C.
4. Hybrid Lab (Class 11)
Click 🧬 Hybrid → filter sp³d/sp³d²/sp³d³ → tap card like XeF₄ square planar, IF₇ pentagonal bipyramidal.
School Theme: Green chalkboard + wood frame, high-contrast chalk text, big buttons for smart-board touch. Use Clear Board to reset, Quiz for quick oral questions (e.g., What is hybridization of SF₆?).
